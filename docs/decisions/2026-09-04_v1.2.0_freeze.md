## Context

The original v1.1.0 freeze was trained on 45 features including 19 future-information columns (label leakage). All metrics from that freeze (test ROC-AUC 0.981 / PR-AUC 0.876; walk-forward OOS PR-AUC mean 0.968) were **invalid**. A formal leakage audit (T21) identified the root cause: the blacklist used exact-match only, catching `mfe_r_h16`/`mae_r_h16` but missing other non-registry columns. A repair chain (team v2, t1 ML_Engineer + t2 QA_Auditor) was executed, followed by a full re-freeze with honest metrics.

### Repair Chain

| Fix | Description | Evidence |
|-----|-------------|----------|
| F3-WF | `walk_forward_validation` passes `impute_medians` train-only into `calibrate_model`/`evaluate_on_test` — eliminates imputation leak into test-fold | 5 folds clean, no NaN/no crash; WF OOS PR-AUC mean 0.3552 |
| F3-CLI | `train_model.py` wires `impute_medians` into calibrate/eval | `xauusd-train` rc=0, no NaN crash |

| F1-RACE | Race generator guard with `--force` | Run without `--force` → `[skip]`, md5 unchanged |

**QA_Auditor (t2) verdict:** PASS — independently reproduced CLI/WF/top-prob, strict-check WF no null/NaN, md5 snapshot verified 13/13 with empty diff after re-run.

## Frozen Decisions

1. **Baseline strategy = B (confirmed events)** — better win rate + expectancy, fewer trades, causal.
2. **`sweep.group_rule: "first"`** is the frozen default (config-driven, QA F1).
3. **Direction vocabulary** frozen at sweep-side (`bullish`/`bearish`) in the event table, with `normalize_event_direction` as canonical bridge to trade-side (`long`/`short`).
4. **Cost model frozen** (half-spread/slippage/commission per guide §17; `net_result_r` is the cost-adjusted headline metric). Current config costs are zero-cost placeholders; a non-zero cost config is required before paper trading.
5. **Model is WEAK** (test PR-AUC 0.2275 ~ baseline positive_rate 0.1795) — used **only for ranking**, not as trade decision maker.
6. **Top-prob subsets show PF > 1** but all P(net>0) within Wilson 95% CI containing baseline 42.24% — **no statistical evidence** of separation from baseline; results are suggestive only.
7. **Do NOT trade ML as-is** — with realistic costs (~0.05R/trade), overall expectancy becomes negative. Continue using rule-score strategy B as decision maker; ML is reference only.
